# GitHub Upload Guide

1. Extract this project folder.
2. Open GitHub and create a new repository named:
   `Student-Record-Management-System`
3. Keep the repository Public if your professor needs to open it.
4. Upload all files and folders from this project.
5. Before uploading, run the Python program yourself.
6. Take screenshots of the output and put them inside `screenshots/`.
7. Commit the files with a message such as:
   `Completed Student Record Management System`
8. Open the repository and check that README.md, the Python file, exercises, report, flowcharts and screenshots are visible.
9. Copy the repository link and submit it to your professor.

## Important
Do not submit screenshots showing someone else's computer or output. Run the program on your own VS Code and capture your own screenshots.

# Student Record and Academic Management System

## Data Structures and Collection Management

### Project Objective
This project is a simple Python-based Student Record and Academic Management System. It stores student information and performs basic operations such as adding, searching, updating, deleting and displaying records.

The project is written at a first-year BTech Python level and demonstrates the five data structures required in the assignment:
- Strings
- Lists
- Tuples
- Sets
- Dictionaries

## Main Operations
1. Add a student
2. Search by roll number
3. Update student information
4. Delete a student
5. Display all records
6. Calculate average marks
7. Find highest scorer
8. List students by department
9. Count students
10. Show unique departments

## Data Structures Used

| Data structure | Use in this project |
|---|---|
| String | Name, department, email, address, subject names |
| List | All students, subjects, marks |
| Tuple | Fixed roll/name registration information |
| Set | Unique departments |
| Dictionary | Complete student record |
